Getting a good result

  • Shoot straight on if you can — from the dock, level with the transom. The tool corrects perspective, but a squarer photo always looks better.
  • Place the four corners around the area the name should occupy, in order: top-left, top-right, bottom-right, bottom-left. The lettering fills that box.
  • Not sure how big? Work out the right letter height first with our size calculator, then mark that area on the photo.
  • Script fonts look elegant on screen but have hairline strokes — below about 6 in cap height they get fragile in 3 mm steel. We will flag that when you order.
